# 🐍 Python Robotics Roadmap

## 🎯 Goal

Become a strong Python programmer and use Python to build
standalone robotics projects **without ROS 2**.

## 🎓 1. CS50's Introduction to Programming with Python (CS50P)

**Main online course**

https://cs50.harvard.edu/python/

Learn:

- Variables
- Functions
- Conditions
- Loops
- Exceptions
- Libraries
- Unit testing
- File I/O
- Regular expressions
- Object-oriented programming

**Goal:** Understand programming fundamentals and become comfortable
writing Python programs.

---

## 🎓 1. Programming for Everybody (Getting Started with Python)

This is your first online course :  https://www.coursera.org/organizations/reliance-family/learn/python?specialization=python

Learn:

- Variables
- Expressions
- Conditions
- Loops
- Functions
- Basic data structures
- Files
- Basic Python programming

Goal: Understand programming fundamentals and become comfortable writing simple Python programs.

---

## 📘 Python Crash Course — 3rd Edition

**Eric Matthes — 2023 - Main beginner book**

Use this alongside CS50P for additional practice and projects.

Focus on:

- Python fundamentals
- Data structures
- Functions
- Classes
- OOP
- Files
- Testing
- Practical projects


**Goal:** Build enough Python knowledge to work independently.

# 🔄 Learning Method

For every topic:

**Learn → Code → Build → Test → Refactor → GitHub**

Don't wait until you finish every course before starting projects.

---

# 📚 Learning Order

CS50P / Programming for Everybody (Getting Started with Python)
↓
Python Crash Course + Python Data Structures
↓
Small Python Projects
↓
Fluent Python
↓
NumPy + Mathematics
↓
Robotics Algorithms
↓
Standalone Robotics Projects

---

# ❌ Not Needed

You do NOT need to study multiple beginner Python courses simultaneously.

**CS50P** is your main online course.

**Python Crash Course** is your main beginner book.

**Programming for Everybody** is optional and does not need to be completed.
